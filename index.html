動かす 直線 \(y=ax+b\) を自分で動かそう

a と b は「定数（決まった数）」、x・y は「変数（グラフ上の点）」。スライダーで a・b を変えると直線が動きます。

\(y=x\)
1
0
直線 y=ax+b 切片 b（x=0 のときの y） 傾き（xが1増→yがa増）

要点 ここだけは押さえる

傾き a ＝ 変化の割合

\(a=\dfrac{y\text{の増加量}}{x\text{の増加量}}=\dfrac{\Delta y}{\Delta x}\)。「x が 1 増えると y が a 増える」。だから yの増加量 = a × xの増加量。上のグラフで緑の三角形（Δx=1, Δy=a）を見よう。

切片 b

b は x=0 のときの y の値。グラフが y 軸と交わる点（ピンクの点）。

2点あれば直線は決まる

通る2点が分かれば、①傾き \(a=\dfrac{y_2-y_1}{x_2-x_1}\) を出す → ②どちらかの点を代入して b を求める、の順で式が作れる。

\(ax+by=c\) の形は「y＝」に直す

\(2x+3y=6\) → \(3y=-2x+6\) → \(y=-\dfrac{2}{3}x+2\)。こうして初めて傾き（\(-\frac23\)）と切片（2）が読める。

教達検 第1回（R2・R3・R6・R7）の1次関数を分析。出るのはこの6タイプで「これが解ければOK」。各タイプの「次のステップ→」で解き方を1行ずつ確認しよう。
緑ラベルは近年（R6・R7）の実際の出題例。

① 式から傾きを求める

例（R3 大問2）：\(2x+3y=6\) のグラフの傾きを求めなさい。
まず y について解く：\(3y=-2x+6\)
両辺を 3 でわる：\(y=-\dfrac{2}{3}x+2\)
\(y=ax+b\) の a が傾き → 傾き \(=-\dfrac{2}{3}\)

② 変化の割合・代入

例（R3 大問7）：\(y=-3x+15\) で、x の増加量が 4 のとき、y の増加量を求めなさい。
変化の割合 ＝ 傾き ＝ \(-3\)（xが1増えるとyは3減る）
yの増加量 ＝ 傾き × xの増加量 ＝ \(-3\times 4\)
yの増加量 \(=-12\)
R7 大問7-1：\(y=\dfrac{1}{3}x+10\) 上の点Pで、x座標が 9 のとき y座標を求めなさい。
直線上の点 → x=9 を代入するだけ
\(y=\dfrac{1}{3}\times 9+10=3+10\)
y座標 \(=13\)（Pの座標は \((9,13)\)）

③ 2点（条件）から式を求める

例（R2 大問7 改）：2点 \(B(-4,0)\)・\(C(0,5)\) を通る直線の式を求めなさい。
傾き \(a=\dfrac{5-0}{0-(-4)}=\dfrac{5}{4}\)
C は y 軸上の点なので、切片 \(b=5\)
\(y=\dfrac{5}{4}x+5\)
R6 大問7-2：2点 \(A(-2,-12)\)・\(B(4,6)\) を通る直線の式を求めなさい。
傾き \(a=\dfrac{6-(-12)}{4-(-2)}=\dfrac{18}{6}=3\)
\(y=3x+b\) に \(B(4,6)\) を代入：\(6=3\times4+b\) → \(b=-6\)
\(y=3x-6\)

④ 2直線の交点（連立）

例（R3 大問7）：\(y=-3x+15\) と \(y=x-9\) の交点 C を求めなさい。
y が等しいので \(-3x+15=x-9\)
\(-4x=-24\) → \(x=6\)
\(y=6-9=-3\) → \(C(6,-3)\)
R7 大問7-2：\(y=\dfrac{1}{3}x+10\) と \(y=-2x-4\) の交点 A を求めなさい。
\(\dfrac{1}{3}x+10=-2x-4\)、分数を消すため両辺×3：\(x+30=-6x-12\)
\(7x=-42\) → \(x=-6\)
\(y=-2\times(-6)-4=8\) → \(A(-6,8)\)

⑤ 軸との交点（切片・x切片）

例（R3 大問7）：\(y=-3x+15\) と x 軸・y 軸との交点 A・B を求めなさい。
y 軸との交点 A：x=0 を代入 → \(y=15\) → \(A(0,15)\)
x 軸との交点 B：y=0 を代入 → \(0=-3x+15\)
\(3x=15\) → \(x=5\) → \(B(5,0)\)
R7 大問7：\(y=-2x-4\) と x軸・y軸との交点 C・D を求めなさい。
x 軸との交点 C：y=0 → \(0=-2x-4\) → \(x=-2\) → \(C(-2,0)\)
y 軸との交点 D：x=0 → \(y=-4\) → \(D(0,-4)\)（切片がそのままDのy座標）

⑥ 図形との融合（面積・回転体）

例（R3 大問7）：\(A(0,15)\)・\(B(5,0)\)・\(D(0,-9)\) の △ABD を y 軸のまわりに1回転させた立体の体積を求めなさい。
A・D は y 軸上、B だけ軸から水平に 5 離れている → 回転で半径 5の円ができる
上の円錐：底面半径5・高さ \(15\)、\(V_1=\dfrac13\pi\cdot5^2\cdot15\)
下の円錐：底面半径5・高さ \(9\)、\(V_2=\dfrac13\pi\cdot5^2\cdot9\)
合計 \(=\dfrac13\pi\cdot25\cdot(15+9)=\dfrac13\pi\cdot25\cdot24\) → \(200\pi\ \text{cm}^3\)

⑥ 図形との融合（面積・等積変形）R7

R7 大問7-3：\(B(0,10)\)・\(C(-2,0)\)・\(D(0,-4)\)。①\(y=\dfrac13x+10\) 上の点P(x座標は正)について、△BCD と △BCP の面積が等しいとき、2点 D・P を通る直線の式を求めなさい。
コツ＝等積変形：△BCD と △BCP は底辺 BC が共通。面積が等しい ⟺ P は「D を通り BC に平行な直線」の上にある
直線 BC の傾き \(=\dfrac{10-0}{0-(-2)}=5\)。D を通り BC に平行 → \(y=5x-4\)
P は①との交点：\(\dfrac13x+10=5x-4\)、×3で \(x+30=15x-12\) → \(x=3\)（正でOK）、\(y=11\) → \(P(3,11)\)
求める直線は D・P を通る \(y=5x-4\)（D自身を通る平行線がそのまま答え）→ \(y=5x-4\)
※ R2 大問7 も「△ABC と面積が等しい点 P」の面積タイプ（答 \(\frac{52}{5}\)）。座標→長さ→面積・等積変形の流れは共通。
